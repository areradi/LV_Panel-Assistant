# PanelCalc Pro desktop direction

Reference: the user-approved three-column Windows 11 screenshot concept from this chat.

Composition: left navigation, central editable workflow, persistent right-hand calculation context. Advanced project fields collapse to keep the initial form focused.
Materials: Windows system backdrop when supported, opaque layered cards to maintain readable text; no simulated compliance or success indicators.

The summary and enclosure dimensions use real engine output. The formula drawer explicitly identifies an aggregate reference current before diversity and reserve factors. The enclosure wireframe is a contextual overview, not a fabrication drawing. Product version numbers and sample screenshot values are not used as calculation results.
