## سازگاری‌های اصلاح‌شده

- جست‌وجو از مسیر مطلق دیتابیس استفاده می‌کند؛ اجرای EXE به پوشهٔ جاری وابسته نیست.
- دریافت وب از Thread پس‌زمینه انجام می‌شود؛ Queue و Poll رابط، نتیجه و خطا را
  فقط در Thread اصلی Tk تحویل می‌دهند. نتیجهٔ جست‌وجوی لغوشده نمایش داده نمی‌شود.
- طول کابل NaN، Infinity، صفر، منفی یا متن نامعتبر را نمی‌پذیرد.
- تغییر ورودی، وضعیت Workflow را قدیمی می‌کند؛ مراحل موجود پس از محاسبه ثبت می‌شوند.
- خلاصه، In واقعی تجهیز را از جریان طراحی تفکیک می‌کند؛ پل و تنظیمات ناموجود حدس زده نمی‌شوند.
- ابعاد W/H/D با واحد mm مشخص‌اند. علامت‌های Unicode isolation که در Tk مربع
  دیده می‌شدند از رشته‌های نمایشی خلاصه حذف شدند.
- هشدار مقدماتی SPD شناسهٔ مستقل و ترجمهٔ سه‌زبانه دارد؛ وجود LPS از نوع SPD حدس زده نمی‌شود.
- پوشه‌های موقت خروجی کنار مقصد ساخته می‌شوند؛ PDF برای هر اجرا Profile مستقل دارد
  و اگر مرورگر اول شکست بخورد مرورگر نصب‌شدهٔ بعدی را امتحان می‌کند.
- ساخت اجرایی، نام یکسان PanelCalc-Pro دارد و فایل‌های واسط را در build نگه می‌دارد.
